# Getting started

## Supported MongoDB versions
MongoCamp Server is tested against **MongoDB 6.0, 7.0, 8.0 and 9.0**, these are the supported versions.
MongoDB 4.4 and 5.0 are not tested anymore and are not supported: they may work, but problems with them are not fixed.
